`components.json` tells the shadcn CLI where to write source files, which
stylesheet contains Tailwind, and how to resolve the Orchid registry.

## Recommended configuration

Keep the compatible values generated by `shadcn init`, then verify these
settings:

```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "base-nova",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "src/styles.css",
    "baseColor": "neutral",
    "cssVariables": true,
    "prefix": ""
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  },
  "registries": {
    "@orchid": "https://orchid-ui-hitpay.vercel.app/r/{name}.json"
  }
}
```

Use the actual global stylesheet path generated by your framework if it differs
from `src/styles.css`. Ensure `@/*` resolves to your source directory.

## File destinations

Orchid registry files declare their own target alias:

- `@ui/button.tsx` resolves through `aliases.ui`, normally to
  `src/components/ui/button.tsx`.
- `@components/schema-form.tsx` resolves through `aliases.components`,
  normally to `src/components/schema-form.tsx`.

Do not manually choose a destination when adding an item. The registry target
and your aliases determine it consistently.
