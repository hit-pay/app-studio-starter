Use **`ResourcePicker`** when users must search, filter, and confirm HitPay list records (**products, orders, charges, invoices**). Wire **`load`** to the same query parameters documented in App Studio **`app/docs/hitpay/`** (`products.md`, `orders.md`, `charges.md`, `invoices.md`). Mount **`ResourcePickerProvider`** with a **`load`** function once near the root, then call **`useResourcePicker()`** and **`await pick({ type, … })`**. The promise resolves to selected rows or **`undefined`** when cancelled. Choose it instead of a full-page table or `Select` for long lists; use **`Select`** with `description` / `image` for small static option sets.
