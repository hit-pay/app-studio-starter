Use `Select` for choosing one or more values from a finite option list. Each option is `{ value, label }` at minimum; add **`description`** and **`image`** for two-line or thumbnail rows in the menu (the closed trigger still shows **`label`** only). Use **`renderOption`** when you need full control of the row. Choose `ResourcePicker` when users must browse paginated HitPay catalog records.
